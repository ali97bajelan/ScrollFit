## Matrix template to expand in the report

Use one row per combination, not one aggregate PASS for a group:

| Exercise | Lens | Entry path | PG01–PG05 scenario references | Manual/app reps | Result | Evidence / issue |
|---|---|---|---|---|---|---|
| Expand all four exercises | Front / rear | Advance / blocker / exercise-only | Required IDs | Not measured | NOT RUN | — |

Accuracy needs eight rows with three trial counts each. Accessibility needs explicit locale, theme, size, font, TalkBack and audio conditions. A subset of combinations can share a synthetic fixture test, but the required 24 physical happy-path journeys cannot be replaced by that fixture.

Exit: all P0 cases pass with actual evidence. Otherwise report the specific failed/blocked acceptance targets and remaining work.
