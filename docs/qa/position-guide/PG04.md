# PG04 QA — Start/countdown/run isolation

Links: [tasks/shared requirements](../../EXERCISE_POSITION_GUIDE_TASKS.md), [spec](../../superpowers/specs/2026-10-24-pg04-workout-flow-design.md), [plan](../../superpowers/plans/2026-10-24-pg04-workout-flow.md).

**Execution state: all scenarios NOT RUN.** Record actual/expected, revision, tester/date, mode/entry path, environment and evidence per ID. Automated races use fake clocks, suspend delegates and fake cameras; validate persisted outcomes through test repositories. Exercise-only may save activity after completion but must never award time; standalone trials save neither.
