## Repair follow-up — 2026-10-26

The Compose 1.12.1 test compilation issues were repaired: semantics assertion/fetch helpers are called as members, tests needing `activity` use `createAndroidComposeRule<ComponentActivity>`, and the camera cleanup test removes its surface through composition state. `./gradlew :app:testDebugUnitTest :core:test --rerun-tasks --console=plain` passed **22 app and 311 core tests**. The resulting app Android-test APK compiled and `./gradlew :app:connectedDebugAndroidTest --console=plain` passed **36/36 tests** on Android 16 / API 36.1, including all four `ProductionLoopTest` fixtures. The first integrated rerun exposed a separate slow history test traversal; replacing per-item semantics search with the list's `ScrollToIndex` action reduced the history performance class from 117.6 seconds to about 5 seconds and removed the suite's missing-hierarchy failure. The final app XML is [app-connected.xml](../../../verification/project-review/2026-10-26-repair/app-connected.xml).
