# Room schema exports

Room schema exports are generated by the Android build and must be retained only from their matching historical source/build. T15 adds an explicit additive migration from version 2 to version 3. The directory currently contains `2.json` and `3.json`; no v1 export is present. The Android build now configures in the available environment, but the original v1 export and migration-fixture validation remain outstanding. Do not fabricate or relabel a schema to fill that gap.
